Окно AI-ответа, анимации ожидания

Думающие сферы

Девять состояний из открытой библиотеки thinking-orbs перенесены в ванильный JavaScript без сборки. Каждое показано в двух палитрах: исходной монохромной и в зелёной гамме Housebook с золотистым акцентом.

Лицензия MIT, коммерческое использование разрешено Автор Jakub Antalik, репозиторий github.com/Jakubantalik/thinking-orbs, текст лицензии в файле LICENSE рядом.

В системе включено ограничение анимации: сферы показаны статичным кадром.

Сферы ставятся на паузу вне экрана и на скрытой вкладке.

Как это встаёт в окно AI-ответа

Три шага ожидания из концепта v1 (шаг 1 из 3, 2 из 3, 3 из 3). Крупная сфера по центру, малая (20 px) в шапке окна. Анимации те же, что в каталоге ниже.

Все девять анимаций

Слева исходная палитра на тёмной подложке, справа палитра Housebook. Крупная сфера 168 px (тот же рисунок, увеличенный), ниже родные размеры библиотеки: 64 px для аватара чата и 20 px для строки текста.

Нагрузка на этом устройстве

Измеряется вживую на этой странице: сколько точек рисует кадр сферы 64 px и сколько миллисекунд на него уходит. Одна сфера это один холст 2D, без blur-слоёв и фильтров.
