# Housebook kit

Общий набор для макетов страниц сайта: стили, интерфейс, 3D-сцена и данные. Всё на относительных путях, внешние только шрифты Google и three.js r128 с cdnjs (его подгружает `hb-scene.js` сам и только на сильных устройствах).

| Файл | Что это |
|---|---|
| `hb.css` | токены, светлая тема и «Сумерки», все компоненты |
| `hb-ui.js` | поведение интерфейса (тема, меню, сортировка, помощник, формы и т.д.) |
| `hb-scene.js` | 3D: планета, дом, 3D-столбцы; один WebGL на страницу. Задники `.bg3d` (с 07.10.2026) и «Кровли» `data-roofs` (с 06.10.2026) плоские паттерны CSS, не 3D |
| `hb-data.js` | снимок данных от 22.09.2026: `HB_CITY` (6 рынков), `HB_COUNTRIES` (11 стран), `HB_MARKETS`, `HB_MARK` |
| `kit.html` | витрина всех компонентов и режимов 3D с подписями «как использовать» |
| `glavnaya.html` | главная на ките |
| `../_shablon.html` | скелет страницы с комментариями «МЕНЯТЬ», лежит в корне папки макетов |
| `patterns/` | 8 паттернов брендбука в 4 вариантах (`bumaga`, `podlozhka`, `zelenyy`, `temnyy`): бесшовные плитки, фон задников, полосы `.band--pat` и запасной слой без WebGL |
| `favicon.*`, `icon-*.png`, `apple-touch-icon.png`, `site.webmanifest` | иконки и манифест |

## Подключение

Шаблон лежит в корне папки макетов рядом с `kit/`. Для такой страницы префикс ассетов `kit/`; для страницы внутри `kit/` префикса нет (как в `glavnaya.html`).

В `<head>`:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Geologica:wght@400;500;600&amp;family=IBM+Plex+Sans:wght@400;500;600&amp;display=swap">
<link rel="stylesheet" href="kit/hb.css">
<!-- тема «Сумерки» до первой отрисовки, иначе страница мигнёт светлой -->
<script>try{if(localStorage.getItem('hb-night')==='1')document.documentElement.classList.add('dusk')}catch(e){}</script>
```

Сразу после `<body>` идёт SVG-спрайт (логотип `#hb-logo`, крыша `#hb-roof`, иконки Lucide `#i-*`). Его проще всего скопировать из `_shablon.html` целиком вместе с шапкой, меню, подвалом и помощником.

Скрипты в конце `<body>`, порядок важен:

```html
<script src="kit/hb-data.js"></script>
<script src="kit/hb-scene.js"></script>
<script src="kit/hb-ui.js"></script>
```

Тег three.js на страницу не ставится. Телефон (сенсор, до 899 px), слабый ПК (до 4 ГБ памяти или до 4 ядер), Save-Data или браузер без WebGL получают `html.no-3d` / `html.no-webgl` и паттерны брендбука вместо сцен, three.js при этом не скачивается. Для проверки: `?3d=0` картинки везде, `?3d=1` 3D везде.

Новая страница: скопировать `_shablon.html` (корень папки макетов) рядом под именем страницы и заменить всё с пометкой «МЕНЯТЬ».

## 3D: атрибуты разметки

Сцена сама находит блоки по атрибутам. Блок без WebGL показывает паттерн, отдельно делать ничего не нужно.

| Блок | Разметка | Атрибуты |
|---|---|---|
| Планета | `<div class="hb3d hb3d--globe" data-globe><canvas role="img" aria-label="..."></canvas></div>` | `data-aim="шир,долг"` куда смотреть; `data-pins` страны для пинов (ключи `HB_COUNTRIES`); `data-markets` подсветить рынки; `data-place="right"` сдвиг планеты вправо на первом экране; `data-pin-href` куда ведут пины |
| Дом проекта | `<div class="hb3d hb3d--object" data-object="tower"></div>` | `data-object`: `tower` или `villa`; `data-floors` этажей; `data-floor` подсвеченный этаж; `data-interactive` вращение мышью и клавишами; `data-floor-slider` добавляет ползунок этажа (`.hb3d__ui` с `range` и `output`) |
| Столбцы | `<div class="hb3d hb3d--bars" data-bars='[{"label":"Дубай","v":4200}]'></div>` | `data-prefix`, `data-suffix` к числам; сцена сама строит доступный список `.hb3d__list` с теми же числами |
| Кровли (плоский паттерн брендбука, без 3D) | `<div class="hb3d hb3d--roofs" data-roofs aria-hidden="true"></div>` | без атрибутов |

Поведение: живая анимация только на десктопе без `prefers-reduced-motion`, не чаще 30 кадров в секунду, только для видимых блоков и активной вкладки. На телефоне и при «меньше движения» кадр рисуется один раз. `Save-Data` ставит `html.no-3d`, отказ WebGL ставит `html.no-webgl` и `window.__sceneErr`; в обоих случаях остаются паттерны.

## window.HBScene

Объект появляется только после успешного старта сцены, поэтому вызовы всегда с проверкой `window.HBScene && ...`.

| Метод | Что делает |
|---|---|
| `ready()` | массив `[{type, ready, live}]` по всем блокам |
| `setCity(key)` | сменить квартал у всех задников; `false`, если ключа нет |
| `highlightFloor(n, el)` | подсветить этаж `n` у дома `el` (без `el` у всех домов) |
| `redraw()` | перерисовать все блоки (например после смены темы извне) |
| `info()` | `{live, reduced, phone, px, size, city, err, ...}` для отладки |
| `views` | список видов задника |

```js
window.HBScene && HBScene.setCity('phuket');
window.HBScene && HBScene.highlightFloor(7, document.getElementById('k-tower'));
```

## hb-ui.js: модули

- Тема «Сумерки»: кнопка `.night`, класс `html.dusk`, ключ `localStorage` `hb-night`, событие `hb:theme`; состояние в `aria-pressed`.
- Меню на телефоне: `.burger` открывает `dialog#mnav`, `aria-expanded` синхронно.
- Сортировка: `table[data-sortable]` (или `#markets`), у `th[data-t]` появляется `button.sort`, состояние в `aria-sort`, работает с клавиатуры.
- Появление `.reveal`, счётчики `[data-count]`, анимация `.bars`, подсказка `#hint`.
- Помощник: кнопка `#aid-fab` с крышей и `dialog#aid`; всплывает, когда поле `[data-aid-anchor]` (или `.hero .ask`) ушло вверх, прячется над `.final`.
- Вкладки `.tabs`, галерея `.gallery`, избранное `.fav`, проверка `form.form` (адрес в `data-endpoint`), оглавление `.toc`.

## Соответствие брендбуку

Сверено по `_research/D-brendbuk.md`, пункт за пунктом.

1. **Логотип.** Один источник: символ `#hb-logo` в спрайте; на тёмном и нефрите белый через `currentColor`. Не растягивается, отступы по охранному полю.
2. **Цвет.** Все цвета токенами в `:root`. Акцент `#00732D` только на кнопках, ссылках и мелких акцентах; большие зелёные заливки (финал, бейджи, шапка темы) нефритом `#0E6A40`. В «Сумерках» акцент мятный `#73B28C`, `#00732D` на тёмном не используется. Исправлено против эталона (раздел 10): тинт «Сумерек» `#0E2C1C`, наведение `#8FC1A3`, цвет финального блока нефрит.
3. **Шрифты.** Заголовки Geologica 600, текст и все числа IBM Plex Sans с `tabular-nums`.
4. **Шкала.** H1 48/56 на десктопе и 32/38 на телефоне; H2 24/32 и 20/26; текст 16/25; минимум 12. Внешкальные размеры h1/h2 эталона убраны.
5. **Знак крыши.** Три роли и только они: маркер списка `.roofs` и `.prose ul` (1em на 0.33em); один акцент `.roofed` над главным числом страницы (на главной только над «11», ширина 0.8 высоты числа); разделитель в подвале. Плюс кнопка помощника. Колец нет; метка на карте и пины планеты знаком «u с крышей» (`HB_MARK`).
6. **Микротипографика.** «Ёлочки», буква ё, «Вы» с прописной, неразрывный пробел в числах (1&nbsp;209, 20&nbsp;145), диапазоны дефисом. Длинных тире 0 во всех файлах кита (проверка ниже).
7. **Иконки.** Lucide, толщина 1.75, цвет `#121517` или `#00732D`, на тёмном `#FFFFFF` или `#73B28C`.
8. **Паттерны.** Только фоном (задники секций, полосы, запасной слой без WebGL, заглушки фото): запасной слой без WebGL и заглушки фото; один паттерн на макет, под текстом не больше половины площади.
9. **3D.** Фон, не герой: планета с точечной сушей, на тёмном мятная. Исправлено против эталона: сцена больше не красит `#00732D` на тёмном.
10. **Тон.** Нет «лучший», «уникальный», «премиальный», гарантий доходности. Цифры вместо эпитетов, у каждой цифры источник и дата («Пересчитано 22 сентября 2026», NASA POWER у климата). Из эталона убраны факты про №393, «$35 млн», «9 000+ агентов», «Премиальный сервис».
11. **Цена цветом текста** (`--price: var(--ink)`), решение владельца 06.10.2026; красный только для ошибок и редких акцентов.

## Решения владельца 06.10.2026

- Цена цветом текста (`--price: var(--ink)`); финальный h2 по шкале H2.
- Планета: порядок поворотов «рысканье, затем наклон», вертикальное движение руки не инвертируется после поворота на 180°.
- Числа в `.facts` крупные (`--fs-num-s`, 22px).
- Сортировка: у отсортированной колонки одна стрелка (вверх по возрастанию, вниз по убыванию), у остальных двойная.
- Все `select.select` автоматически становятся своим списком (hb-ui.js, `customSelect`): поиск (по умолчанию при 6+ пунктах, `data-search="on|off"`), множественный выбор через `multiple` с кнопками «Сбросить» и «Готово», группы `optgroup`, клавиатура (стрелки, Enter, Esc, PageUp/PageDown, первая буква), `data-placeholder`. Родной `select` остаётся в DOM: id, `change` и отправка формы работают. Панель в top layer (popover), поэтому поверх любых секций и шапки; не помещается снизу - открывается вверх.
- Липкие элементы не больше 15-20% высоты экрана. Шапка липкая (60-72px). Строка фильтров каталога `.fbar` липкая: 62px на десктопе, 106px (13%) на телефоне. Высокие блоки не липнут: `.filters--sticky` и `data-return="Подпись"` дают кнопку возврата `.ret` внизу слева.
- Фильтры каталога - `form.fbar` (hb-ui.js, модуль fbar) по ресёрчу `_research/F-filtry.md`: одна строка над выдачей, как у Домклика, Яндекса, Циана и Property Finder. Слева поле локации (свой список с поиском и группами), дальше кнопки-группы с попапом (Тип, Спальни, Бюджет, Срок сдачи), справа «Все фильтры» с панелью-диалогом. Ширина кнопки не меняется: выбранное показывает счётчик в зарезервированном месте, кнопка подсвечивается. В попапе «Сбросить» и «Показать N проектов». Под строкой `.fmeta`: «Найдено N», «Сбросить фильтры», сортировка. Спальни - квадратные кнопки с мультивыбором, бюджет - «за объект / за м²», валюта, от и до, без слайдера. Телефон: лента чипов, первой «Все фильтры», попап - лист снизу, панель на весь экран с нижней кнопкой «Показать N». Число N в макете условное, на сайте его отдаёт API.
- 3D-изометрия «Кровли» не используется: блок `hb3d--roofs` показывает плоский паттерн «Кровли».

## Подсказки графиков

Любой точке графика ставится `data-tip="Заголовок&#10;пояснение"`: `hb-ui.js` показывает плашку при наведении, фокусе с клавиатуры (элементу нужен `tabindex="0"`) и касании. Первая строка жирная, следующие мельче. Столбик климата `.bar`, шкала цен `.pscale__*`, строки `.p-types`, шаги `.plan`. 3D-столбики и планета дают подсказку сами: у столбика подпись и значение (своё пояснение кладётся полем `"tip"` в `data-bars`, перевод строки `\n`), у страны число проектов и рынок.

## Паттерны вместо задников-улиц (решения владельца 07.10.2026)

Задники «пролёт по кварталу» (`.bg3d`, бывшие `gorod`, `bashni`, `ulica`, `sverhu`) больше не 3D: это плоский паттерн бренда. Планета, дом и 3D-столбцы остаются сценой.

| Блок | Разметка | Как работает |
|---|---|---|
| Задник секции | `<div class="bg3d" data-pat="izo" aria-hidden="true"></div>` | `data-pat`: `krovli`, `znaki`, `galochki`, `izo`, `nadpis`, `liniya`, `shah`, `planeta`; без `data-pat` изометрия, старый `data-view="ulica"` даёт «Линию». Плитка бесшовная, повтор в масштабе 0.9 от ширины плитки (`--tw`); в финале на нефрите маска к центру |
| Полоса-разделитель | `<div class="band band--pat" data-pat="krovli" aria-hidden="true"></div>` | 160px, масштаб плитки 0.5, без подписей |
| Фон блока | `class="patbg" data-pat="..."` | как задник, без прозрачности |
| График 2D | `<div class="chart" data-bars='[...]' data-suffix="&nbsp;AED" role="img" aria-label="..."></div>` | тот же JSON, что у 3D-столбцов; рисует `hb-ui.js`, подсказки по `tip` |
| Карта рынков | `<div class="dmap" data-dmap data-countries="all" data-href="..."></div>` или `data-pins='[[шир,долг,"Подпись","url"]]'` | вместо Leaflet; метки ближе 12px сливаются в одну (подпись по общему слову, например «Кипр», в подсказке каждая часть) |
| Лайк | `<button class="like" data-like="post-1" data-count="12" aria-pressed="false">...<b>12</b></button>` | `localStorage` `hb-like:<id>`, кнопки с одним id синхронны; `.like--s` прячет подпись; на карточке поверх растянутой ссылки |
| Сноска | `<sup><a href="#src3">3</a></sup>` | прокрутка к источнику в центр экрана, подсветка `.is-flash`, фокус без рамки мыши, адрес обновляется без прыжка |
| Действия в уведомлении | `<div class="notice__act">` с кнопками `btn--s` | кнопка не вшивается в предложение, стоит отдельной строкой |

Плитки собираются скриптом-генератором (лист кратен шагу сетки, случайные цвет и высота берутся по ячейке с периодом листа), поэтому на стыке фигура не режется. «Планета» не плитка, а карта: `cover` без повтора.
